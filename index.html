개발자를 위해 만들었습니다

카카오 상담톡 API를 그대로 노출하지 않고, 쓰기 쉬운 REST API와 서명된 웹훅으로 감쌌습니다

하나의 발송 API

텍스트, 이미지, 파일, 리치 말풍선을 POST /v1/messages 하나로 보냅니다. 메시지 일련번호는 서버가 채웁니다.

curl -X POST https://api.talkconnector.example/v1/messages \
  -H "Authorization: Bearer tc_test_..." \
  -H "Content-Type: application/json" \
  -d '{"channelId":"ch_xxx","userKey":"aBc123",
       "type":"text","text":"안녕하세요"}'

서명된 웹훅

고객 메시지, 상담 시작·종료, 읽음, 개인정보 동의 결과를 고객사별 서명 키로 서명해 전달합니다. 실패 시 자동 재시도합니다.

POST https://your-server.com/webhook

테스트 환경 제공

테스트 채널은 과금되지 않는 별도 환경에서 동작합니다. tc_test_ 키로 개발하고 운영 전환 시 tc_live_ 키만 바꾸면 됩니다.

도입 문의

자주 묻는 질문

카카오와 직접 계약해야 하나요?

아닙니다. TalkConnector가 카카오 공식 딜러로서 허브파트너 역할을 맡습니다. 고객사는 약관 동의만으로 이용합니다.

요금은 어떻게 집계되나요?

카카오 통계 기준 상담방(세션) 수로 매일 04시에 집계합니다. 상담원이 메시지를 보낸 세션만 과금되며 시스템 메시지는 제외됩니다.

사용량을 다 쓰면 어떻게 되나요?

80% 도달과 소진 시점에 메일로 알립니다. 소진되면 상위 요금제로 변경하기 전까지 발송이 중단됩니다. Enterprise는 중단 없이 후불 정산합니다.

재판매할 수 있나요?

가능합니다. 다만 약관에 따라 공급가 이하로 판매할 수 없습니다. 재판매 파트너는 도입 문의로 연락 주세요.

채널을 연결하면 1:1 채팅은 어떻게 되나요?

상담톡을 활성화하면 카카오비즈니스 파트너센터의 1:1 채팅 메뉴는 사용할 수 없고, 모든 상담은 API로 처리됩니다.

상담 내역은 어디에 저장되나요?

카카오는 상담 메시지를 3일만 보관합니다. 웹훅으로 받은 메시지는 고객사 시스템에 저장해 주세요.
