      FAQ
      
자주 묻는 질문

      
더 궁금한 점은 API 문서나 도입 문의로 알려 주세요.

    

    

      
Q1카카오와 직접 계약해야 하나요?
아닙니다. 톡커넥터가 카카오 공식 딜러로서 허브파트너 역할을 맡습니다. 고객사는 약관 동의만으로 이용합니다.

      
Q2기존 상담 시스템에 붙일 수 있나요?
네. 상담 시스템이 메시지 보내기 API를 호출하고, 수신 도메인의 /message 경로로 고객 메시지를 받으면 됩니다. 카카오 상담톡 API와 같은 필드 이름을 쓰므로 기존 연동 코드를 거의 그대로 쓸 수 있습니다.

      
Q3요금은 어떻게 집계되나요?
카카오 통계 기준 상담방(세션) 수로 매일 04시에 집계합니다. 상담원이 메시지를 보낸 세션만 과금되며 시스템 메시지는 제외됩니다.

      
Q4사용량을 다 쓰면 어떻게 되나요?
80% 도달과 소진 시점에 메일로 알립니다. 소진되면 상위 요금제로 변경하기 전까지 발송이 중단됩니다. Enterprise는 중단 없이 후불 정산합니다.

      
Q5재판매할 수 있나요?
가능합니다. 다만 약관에 따라 공급가 이하로 판매할 수 없습니다. 재판매 파트너는 도입 문의로 연락 주세요.

      
Q6채널을 연결하면 1:1 채팅은 어떻게 되나요?
상담톡을 활성화하면 카카오비즈니스 파트너센터의 1:1 채팅 메뉴는 사용할 수 없고, 모든 상담은 API로 처리됩니다.

      
Q7상담 내역은 어디에 저장되나요?
카카오는 상담 메시지를 3일만 보관합니다. 수신 도메인으로 받은 메시지는 고객사 시스템에 저장해 주세요.
